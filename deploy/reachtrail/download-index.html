ReachTrail Downloads

macOS 版の配布ファイルです。ダウンロード後に zip を展開してアプリを起動してください。

⚠️ 初回起動に2ステップ必要です

現在このアプリは Apple の公証（Notarization）未対応のため、初回のみ以下の手順が必要です。残念ながらこの2ステップは省略できません。

  1. zip を展開する（ダウンロードフォルダに ReachTrail が現れる）
  2. ターミナルを開き、以下を実行する：
    xattr -cr ~/Downloads/ReachTrail.app
  3. Finder で ReachTrail を右クリック（または Control + クリック）→「開く」を選択する
  4. 確認ダイアログで「開く」をクリックする

手順3で「開く」が表示されない場合は、一度ダブルクリックしてエラーを閉じてから「システム設定」→「プライバシーとセキュリティ」を開き、「このまま開く」をクリックしてください。

なぜ省略できないか： macOS はブラウザでダウンロードしたファイルに隔離フラグを自動付与します（手順2で除去）。さらに macOS Sequoia は Apple が発行する Developer ID 署名と公証のないアプリをダブルクリックでは完全にブロックします（手順3で回避）。一括解除コマンドも macOS Sequoia で廃止されたため、この2手順が現時点での最短です。

この手順は初回のみ必要です。2回目以降は普通に起動できます。
