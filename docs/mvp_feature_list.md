# ReachTrail MVP機能一覧

## プロダクト情報

- プロダクト名: ReachTrail
- 日本語名: リーチトレイル
- 略称: リチレイ
- MVP用メインリモートリポジトリ名: `reachtrail-app`

## 目的

ReachTrail の初期版で、個人利用として成立する最小機能を定義する。

## 対象範囲

MVPでは、以下の状態を作ることを目標にする。

- 基準地点からのランチ記録が簡単に残せる
- 実距離と難易度を見比べられる
- 自己ベストや履歴を振り返って楽しめる

## 必須機能

### 1. 基準地点管理

- 基準地点を1件登録できる
- 名前と緯度経度を保持できる

### 2. 店舗検索

- 店名検索ができる
- 候補一覧を表示できる
- 基準地点の周辺で絞り込みできる

### 3. 候補選択

- 同名店舗から正しい候補を選べる
- 店舗名、住所、建物名、階数ラベルを確認できる

### 4. 階数補完

- APIから階数が取れた場合は自動反映する
- 取れない場合は手入力できる
- 階数ラベルと数値階の両方を扱える

### 5. ランチ記録登録

- 訪問日時を保存できる
- 制限時間を保存できる
- 店内飲食 / テイクアウトを保存できる
- メニュー、価格、支払い方法、メモを保存できる

### 6. 距離計算

- 基準地点から店舗までの実距離を計算できる
- MVPでは直線距離でよい

### 7. 難易度計算

- 距離とは別に難易度スコアを計算できる
- 階数と飲食種別を反映できる
- `scoreVersion` を保存できる

### 8. 記録一覧 / 自己ベスト

- 記録の一覧表示ができる
- 実距離順で並べ替えできる
- 難易度順で並べ替えできる
- 自己ベスト表示ができる

## MVPで除外する機能

- グループ対戦
- リアルタイムランキング
- 複数拠点管理
- 外部SNS共有
- 自動移動ログ連携
- 高度な地図演出

## 受け入れ基準

- 1件のランチ記録を迷わず登録できる
- API候補だけで足りない場合も手入力で完結できる
- 実距離と難易度の両方が記録画面と一覧画面で確認できる
- スコア再計算に備えたデータが保存される
